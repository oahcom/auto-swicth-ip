## 一、推进总图

**主线**（序即依赖，来自 v3.5 §四）：

```
P0 地基（六件事）──→ P1 机制试点 ──→ P1b 台账双域 ──→ P2 WARP 四分 ──→ P3 其余域收尾 ──→ P4 薄壳化 ──→ P5a/P5b 目录治理 ──→ 终态窗 ──→ 终态验收
```

（各段完成判据见 §三；P1 收尾含 revert+exec 降级演练，P1b 为拆分映射排「P1/P2 间」的台账双域，P2 内序枢纽最后，P3 末锁序成环检查+交接物同步，P4 双实例演练须在终态窗前，终态窗=生效重启第 2 次，终态验收=§六 12 条。）

**为什么是这个序**（每步「为何必须在此」）：
- **P0 先于一切搬运**：差分门禁要有冻结基线（P0-2）、清单要有唯一权威源（P0-3/5 生成器与机器账）、搬家的显式例外要先清零（P0-6 位置敏感名）——没有地基，搬运记录写不出、等价条件定不了、回归归不了因。
- **P1 试点先于批量**：宿主注入「机制可行≠纪律可达」（warp_line_worker 先例只证机制）；先在日志域+9router 面两个小域把纪律跑通、把影子守护与演练做掉，风险圈在最小面。
- **P2 内序 refresh→select→lines→tunnelB→tunnelA**：依赖由浅入深，**枢纽（tunnelA）最后**——枢纽先动则牵一发而全链无处安放。
- **P3 覆盖其余域**：槽位原语与 rotate **同批**（语义耦合）；锁常量与单实例锁函数**永不搬离**（R4 对冲）。
- **P4 在域搬完后**：辅助大文件薄壳化是「实体进包、根留壳」的收尾型手术，域未定型前做=返工。
- **P5 最后**：目录治理的输入是「终态模块布局」；P5a（清未引用）先于 P5b（被引用者搬家），因为断链风险只在 P5b。
- **终态窗在 P5b 后**：生效重启只有 2 次额度（P1 窗+终态窗），终态窗一开必须一次到位——所以前置=P3 终态窗预演+P4 双实例演练+四件交接物同步。

**两级验证**：域末全量测试（约 2~3 分钟/域，17 域合计验证墙钟 ≈35~55 分钟，实测口径 2:04~3:13@WSL）+依赖方向检查（秒级）。总工时**待 P0-5 单位数产出后另估**（不预排日历——daemon.py 活跃漂移，排期会假精确）。

## 三、工作包任务书

> 体例统一：**为何在此**（因果）→ **做什么**（逻辑层，不贴代码）→ **前置**（对齐点+依赖工作包）→ **完成判据** → **产出档案**。风险列引用 v3.5 §五 R1~R15。

### P0-1 · 选线、衔接裁决与并行期协议

**为何在此**：改造分支与 stage1a（领先 25 提交）的关系不确定，则差分基线的「主线」不确定，搬运记录的位置证据就悬空；并行期有人热修主线=改造分支踩踏（R7）。这两件事是「开工资格」本身。
**做什么**：
1. **选线裁决**：stage1a 合入 or 弃用，按双向权重清单裁决（合入权重/弃用权重各列，机制分档）；**gate-module-boundary.md 三列表无论选线先摘档留档**（它是指向检查的输入）。
2. **并行期协议四子件**：①冻结面（三问式：冻什么/谁维护/怎么验）②分支拓扑（改造分支独立；域移动基于最新主线重放；差分两跑禁外提交）③热修通道三要素（冲突优先序=主线语义为准；落点重映射=按搬运记录在**新落点**改写、禁 patch 旧位置；验证=三联单重跑+清单重生成+校准重跑）+**外漂移恢复程序**（独立产出项：步骤/角色/判据/时限/与解冻额度的关系）④部署门——**独立检查脚本，install/h2-install/remote-deploy 三入口统一调用且挂 ExecStartPre**（「与」非「或」：覆盖「改文件+restart」必须有启动前检查）；**标记锚定=将执行文件集内容指纹**（沿指纹三定；热修/直接编辑的取信程序入档案库）；**失败语义显式化**（fail-closed 配 Restart=no 或预定义恢复；fail-open 必须声明盲区）。
3. 工作树收口；基线快照在 WSL 内执行（避免 UNC/9p 路径层失真）。
**前置**：对齐点 1、2、6、10。
**完成判据**：选线裁决书+摘档件入库；并行期协议四子件齐（含外漂移恢复程序与部署门失败语义）；部署门脚本在三入口接通且 ExecStartPre 挂载实测有效；工作树收口证据+基线快照三件套入库。
**产出档案**：选线裁决书、gate-module-boundary 摘档件、并行期协议、部署门脚本与指纹标记规格、基线快照。
**风险**：R7（并行踩踏）、R12（清单过期）、R5（部署关卡空转）。

**做什么**：在当前活跃测试面（收集数时点值，P0 重采）上**连续 3 次运行红集同构后冻结**（现值参考=5 条稳定红（config×2、channel_report×2、channel_ban_hold×1）+flap 单列（test_fidelity_channel_lock），**皆为时点值须重采**）；flap 豁免=owner 签字入附件；红因三分法（对应「修代码」授权边界——意外红/设计红/flap 的处置各异）。
**前置**：对齐点 14（v3.5 明文：P0-2→§八 14）；对齐点 5 的「冻结/解冻双签」口径与本包联动确认（本任务书较 v3.5 收紧项）。**红因修代码边界未拍板不许动红**。
**完成判据**：3 次红集同构记录（含收集数）入档案库；冻结基线声明成立；EXPECTED_RED（有意设计红登记表）与基线红集合**语义分野**写明（现 EXPECTED_RED 为空≠无红）。

### P0-4 · 跨界函数裁决

**为何在此**：函数归属不清就无法「一域一提交」——跨界函数（被多域共调/职责横跨）随便归哪边都会造成跨域耦合或搬不动；**副作用链**（被模块级副作用语句直接调用的函数族）必须留宿主，否则搬走后 import 期副作用时序断裂（R8）。名单必须按「反向可达闭包+入选理由=可达路径」产出，不许拍脑袋。
**做什么**：
1. 跨界函数逐个裁决归属（裁决记录=归属+理由+对调用方的影响）——**先于符号清单定稿**；拆分映射点名类必须逐个落位（_BoundedPool 类+两模块级实例化点 _health_pool/_io_pool、_RotateHandler 类、ErrorWindow 类、2 个 logging Filter 类）；

3. 9router 读写门控面归属裁决；
4. **副作用链名单产出**（反向可达闭包，入选理由列）——留宿主，成员 §八 15 定盘冻结。
**前置**：P0-3 生成器；对齐点 8、15（副作用链名册）。
**完成判据**：跨界函数 100% 有裁决记录；副作用链名单带理由列并定盘；门控面归属成文。
**产出档案**：跨界裁决书、副作用链名册。
**风险**：R8、R13。

**完成判据**：七类清单齐且可复现；**daemon.py≤L 的 L 值在此钉死**；生效性抽查每类≥S 的 **S 建议值**在此产出（→§八 15 确认）。

**风险**：R12、R13、R3。

### P0-6 · 位置敏感名清零 + 判据预改造冻结 + 基建收敛

**为何在此**：位置敏感名（`globals()` 反射/`__file__` 派生/`global` 语句——值由「代码所在位置」决定）**搬家即变语义**、无日志、测试未必红（e546614 硬编码路径已炸过，R2/C 类）。清零是「只移不改」的显式例外，必须在任何搬运前做完。判据自身也会随搬运断裂（测试里的硬编码路径/行号），故判据要**预改造+校准+冻结**。基建收敛（工具/单源/档案库）是 P1 起步的工具面。

## 五、横切义务（每工作包默认生效）

1. **只移不改**：diff 白名单=机械伴随+执法必然改写（别名删除/默认参数哨兵化/注释引用同步/格式重排/副作用链具名函数化）留痕；其余一律进发现栏三字段+位置证据（R6）。
