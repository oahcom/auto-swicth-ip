## 甲级

**A1 优先规则无定义**（D3#1+D2#1 双命中）｜裁决：成立
「每节点恰属一类+优先规则」断言引用了不存在的规则——白名单③与「状态登记」双计同一批赋值节点、⑥与装配/启动编排跨箱、main 定义节点双读法；无规则则分类函数非良定义，闭环式不可判。
→ 折入：闭式有序优先清单（四类先于白名单：命中登记表判据的赋值归状态登记、③只收非登记表标量/容器；列名命中⑥归⑥；main 定义节点归启动编排、bind 调用节点归装配）+重叠样本各一入档+为 P0-5 交付列。

**A2 ClassDef 无归箱**（D6#1+D2#3 双命中；R5 A1 折入残项）｜裁决：成立
五类定义（_BoundedPool×2 Filter/ErrorWindow/_RotateHandler）在白名单六形态+四类中无箱可归，闭环式恒差 5；_BoundedPool 被模块级实例化为跨域共享线程池（_health_pool/_io_pool），构造点命名空间处置未裁决。
→ 折入：附表补「5 类终局归属」行（2 Filter→logging_setup、ErrorWindow→monitor9、_RotateHandler→rotate_api、_BoundedPool+两实例化点同条裁决）；白名单第⑦形态「豁免类显式列名」或「终态 ClassDef=0」断言二选一入 §八 15。

**A3 等价条件全集无唯一权威源**（D4#1）｜裁决：成立
「全集」文内指三个集合（第四联闭合单位/不变量声明全集/映射表行集），互不对齐；「不变量→条件」拆条规则无定义（tier 五要素是逐轮补出来的，换执行者拆出不同条数）；映射表射程只写四断裂点而 §七三联单适用全部护栏。
→ 折入：「等价条件全集≡护栏清单机器账中该护栏 ID 下按固定问项展开的条件行集」（契约五问+先后序逐问必答、每答成条、禁自由合并）；映射表射程扩到全部护栏 ID，零行即缺口。

**A4 部署门三缺陷**（D6#2；R5 A3 折入文本内含矛盾）｜裁决：成立
①「或挂 ExecStartPre」与覆盖主张矛盾（「改文件+restart」路径只有 ExecStartPre 拦得住，脚本-only 分支覆盖落空）；②「批次/分支标记」锚定 git ref 对该路径恒绿（它不动 git ref）；③门失败语义未定义（ExecStartPre=崩溃循环 vs 脚本=fail-safe——「或」字把安全攸关选择藏进等价连接词）。
→ 折入：「或」改「与」或显式覆盖差异；标记锚定=**将执行文件集内容指纹**（沿指纹三定同法）+热修/直接编辑取信程序入档案库；失败语义显式化与 §八 6 Restart 三选联动。
