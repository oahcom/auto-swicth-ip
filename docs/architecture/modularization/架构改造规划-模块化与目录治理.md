## 〇、术语表

| 名词 | 含义 |
|---|---|
| **命名空间** | 模块级「名字→对象」映射表。函数体内名字按「局部→本模块全局→内置」查表。 |
| **裸名调用** | 函数体内直接写函数名。解析在调用时刻，落在该函数**所在模块**的命名空间。 |
| **monkeypatch** | 测试技术：运行期把某名字换替身，用完恢复。 |
| **接缝（seam）** | 测试注入替身的可替换点。本仓=测试对**各模块命名空间**写入的全部名字（四类分账见 §1.1）。 |
| **早绑定** | def 时刻固化：默认参数值/基类/装饰器/注解。`from x import y` 不是早绑定——**但副本不跟随宿主 setattr 重绑**，域模块取共享名只许经宿主查找、禁 from-import。 |
| **晚绑定** | 解析推迟到调用时刻。裸名与「宿主.名字」均是。 |
| **位置敏感名** | 值由「代码所在位置」决定：`globals()` 反射、`__file__` 派生、`global` 语句。搬家即变语义——「只移不改」的显式例外（§3.2）。 |
| **宿主注入** | 共享状态的命名空间对象（宿主）传给功能模块；共享名字一律「宿主.名字」。 |
| **宿主转发绑定** | 宿主上为每个接缝名保留的可寻址绑定。**调用期转发**（host.X 薄绑定、调用时查实现表）——与被否的「转手 re-export」（构造时快照、setattr 不跟随）是两回事。 |
| **别名薄壳** | 根位置壳与实现是**同一模块对象**（sys.modules 别名）。两契约：①同对象属性等价 ②壳转发 `__main__` 入口（含参数透传）。**与 spec 整装加载器不兼容**（持 mod 引用者须预改造）。 |
| **差分门禁三断言** | 红集合相等 ∧ 收集数相等 ∧ 新增用例自身全绿后并入基线。 |
| **钉住用例** | 钉住护栏原作用判据（真调判据函数非断言传参）且满足**拆除即红**敏感性（以**变异注入校验**证明：只中和该条件语义、用例必须红）的用例。 |
| **等价条件清单** | 位置敏感名改造的合规上限（逐点枚举，含**先后序问项**）——超出即算顺手改。 |
| **等价条件全集** | 三联单第四联的闭合单位。**唯一权威=护栏清单机器账中该护栏 ID 下按固定问项（契约五问+先后序问项）展开的条件行集**——逐问必答、每答成条、禁自由合并；映射表射程=全部护栏 ID（零行即缺口）。 |
| **三联单** | 护栏移植闭合制：新位置存在+钉住用例绿+旧位置删除+**拆除敏感性校验记录**（第四联，闭合单位=等价条件全集——每条至少 1 条敏感边，空边强制补例或**双签**降级（案卷级护栏禁降、只许补例；降级总量入附件汇总）；时序类钉住用例强制跨域端到端、时间维用显式 now 注入）。 |
| **搬运记录** | 四件套+契约五问（附先后序固定问项）+**锁上下文十槽**（取锁集合与顺序/刻意不取及理由/_locked 调用前提/锁内可调用面与禁做/调用方持锁态/同锁配对原子段/解锁责任含早退/获取与等待语义/**锁对象身份**（锁名字→唯一锁对象，Condition 绑定归属）/**对象生命周期与缺席语义**（创建时机/缺席分支（如 None=不限流）/换绑防护））+宿主绑定名+不变量声明+位置证据。 |
| **副作用链** | 被模块级副作用语句直接调用的函数族（操作定义=2 裸调用+3 条件初始化块的**反向可达闭包**）——无条件留宿主；成员名单由 P0-4 按「入选理由=可达路径」产出、§八 15 定盘冻结。 |
| **校准基线输出档案** | 判据 P0 冻结时留存的各判据输出档案。不变型判据校准对=「旧代码绿（通过）+事故形态红」；目标态判据校准对=「旧代码输出存档为基线+注入违规红」。 |
| **执行档案库** | 执行期全部档案统一落盘规格：git 可读文本+最低字段集（对象/内容/时点/三件套或指纹）+角色矩阵（撰写/复核/批准）+归档时点（P0 定义）。 |
| **事实快照** | 带三件套的实测值。不带三件套的数字不可引用。 |

## 三、方案机理

### 3.1 宿主注入（对 A1+B）

**终态契约三条**：①域模块持有实现；②宿主转发绑定（调用期转发——保 1,307 处直调）；③域模块内部一律经宿主查找——禁裸名、禁局部别名、禁 from-import 共享名、禁 import 模块型接缝名、禁 getattr/vars(host) 动态绕行（或显式标注残余风险）。
**执法=域模块裸名检查器**。射程=模块顶层+类体+函数体（含装饰器位/默认参数位）。违规形态六类：①登记表名字裸名 ②宿主局部别名 ③from-import 共享名 ④import 模块型接缝名 ⑤动态绕行 ⑥**模块顶层 `_host.X` 属性访问**（import 期时序非法）。词表=宿主登记表+第四类键集；带对象指纹。**双规则分档执法**：宿主注入档=六形态（新域模块）；**显式传参档（asip/\*）=check_undefined_names 现有判据基线，不套六形态**——两档以文件路径/import 关系自动识别。**挂载点**（逐一钉死）：check_path_roots 挂 ExecStartPre；裸名检查器/依赖方向挂域提交+阶段末；**check_undefined_names 已存在且四路挂载**（ExecStartPre drop-in+install.sh+**h2-install.sh（告警位）**+remote-deploy.sh——沿用/扩展）；「部署脚本关卡」为挂载点类别。**先例改造试验**：warp_line_worker 合规改造——排期 P0-6，完成判据=过检查器+差分绿+变异抽查。
**注入时机**：daemon 模块体装配段 bind（8 个不调 main 配对=僵尸宿主假绿实证）。断言**拟建**。**语句序：装配段 bind 先于一切状态初始化调用**。

### 3.2 位置敏感名清零（P0 前置；射程=所有待搬实体含 P4 辅助文件）

**① globals() 反射（3 处逐点）**：
- `_load_tier_disabled`：等价条件完整集=首调未绑定态分支+isinstance 守卫+读写同一活值+返回副本+写回序。致害链=瞬态读到预置/旧值→30 条 WG 解禁。**五要素逐条排产真调钉住用例**（新增先绿后并入；test_tier_gate 整函数 stub=假覆盖，标注）。首调未绑定态三选一（§八 15）。
- `_PROBE_BEFORE_ROTATE` 两处：缺省空 dict 跳过/快照迭代/缺失静默降级。

**② `__file__` 派生**：一律读单一路径来源。逐点登记（同形=机械等价；不同形=边角差异进发现栏）。

**③ global 写点**：经宿主读改写、删声明。等价条件逐护栏枚举+先后序语义：
- `_LEDGER_ALLOW_EMPTY_WRITE` 握手：三序+三子语义+端到端四条（负例挂账按「主题→用例名」对账）。
- `_SWITCHED_IN_PROCESS` 证据闸四点条文+按名挂账（10 条=8 标记+2 语义）+置位入口补钉住用例+豁免用例标注敏感范围。
- 其余写点：固定问项=先后序（反例库五例）；P0-5 清单给「序语义」列。

**超出处置**：等价条件=合规上限。发现栏三字段+位置证据。diff 白名单：机械伴随+**执法必然改写**（别名删除/默认参数哨兵化/注释引用同步/格式重排/副作用链具名函数化）留痕；其余进发现栏。

### 3.3 只移不改 + 差分门禁三断言 + 判据冻结

三断言：红集合相等∧收集数相等∧新增先绿后并入。红集 key=稳定测试标识；P4 产 nodeid 映射（缺映射=保守停线）；flap 单列。冻结=连续 3 次同构。
判据四形态 P0 预改造，校准分两类（不变型=旧代码绿+事故形态红；目标态=旧代码存档+注入违规红）。唯一性判据改全产品文件计数+跨模块重复红半边。**拆除敏感性校验（第四联，闭合单位=等价条件全集≡机器账固定问项展开行集）**：每条≥1 敏感边（变异注入）；空边强制补例或**双签降级**（域负责人+独立复核；**案卷级护栏禁降只许补例**；降级总量入附件汇总）；变异不红=换/补用例禁「记录在案」。一次性解冻（双签、至多一次、二次停线）：申请→校准重做（对照校准基线输出档案）→重新冻结；搬动步边界=指纹校验点。
