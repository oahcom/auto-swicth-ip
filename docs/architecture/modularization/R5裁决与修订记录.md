## 甲级

**A1 闭合断言自相矛盾**（D3#1 高＋D6#1 甲，归并；D3 更根本）｜裁决：成立
「白名单+四类之和=顶层 AST 节点总数」按字面立不起来：白名单「六种」是 4 个斜杠组压缩写法、计数无唯一指称、含开放词「等」（与 §七闭式自相矛盾）、「副作用链」无定义无名单；实测 872 顶层节点中 docstring/Expr(Call) 裸调用（urllib3 禁告警、atexit 注册）/非 `__main__` If 块（告警接线、状态库接线）/类定义无归属；白名单②与四类「状态登记」覆盖同一批赋值节点、无互斥规则=双计风险。
→ 折入：白名单改**闭式逐形态清单**（docstring/import 头/标量与容器赋值/豁免函数列名/登记表与绑定表自引用/**模块级副作用语句**（Expr(Call)+非 `__main__` If 块，列名））；删「等」字；「副作用链」钉具体名单；补「每节点恰属一类+优先规则」断言；「副作用链具名函数化」入执法必然改写第五形态；红半边补「塞进常量桶」逃逸形态。

**A2 第四联闭合单位=边 ≠ 等价条件全集；tier 四要素无用例**（D4#2 高＋D3#2 甲，归并）｜裁决：成立
第四联只验「已有边」，空/弱边不进射程——存量实测必然产出：tier 五要素四项零断言（test_tier_gate 整函数 stub=假覆盖）、握手三条子语义 0 敏感边、证据闸本体零直测（test_rotate 还有反向桩）。四联全绿仍可静默丢条件。
→ 折入：第四联闭合单位升「**等价条件全集**」——每条件至少 1 条敏感边，空边强制补例（新增先绿后并入）或签字降级入附件；P0-5 映射表产「条件→用例」缺口清单（四断裂点全域）；假覆盖标注；变异不红=换/补用例，禁「记录在案」了结。

**A3 部署门全路径覆盖**（D5#2 乙高＋D6#2 甲，双命中）｜裁决：成立
批次检查只写在 remote-deploy.sh，但最常见部署路径是「直接改工作区文件+systemctl restart」（三处脚本注释自述）与 install.sh/h2-install.sh——全被旁路；§八 6 是策略约束非技术强制。
→ 折入：检查函数独立成脚本（如 check-deploy-gate），install/h2-install/remote-deploy 三入口统一调用（或挂 ExecStartPre 现网先例）；§八 6 改「策略冻结+技术关卡」双层。

## 乙级

**B1 热修合流缺冲突优先序与落点重映射**（D5#1）：热修约 9 次/日且多落待搬域，热修改动的函数已被搬移时无处置规则——「打在死位置」=修复不生效。→ P0-1③ 补三要素：冲突以主线热修语义为准/按搬运记录「改写后形态」在新落点改写禁 patch 旧位置/该域三联单重跑。
**B2 锁谓词三口径未钉**（D3#3）：「赋值」含不含 AnnAssign（1 条普通+1 条恶意注解赋值可同时骗过存在性与形式谓词——案卷形态借道复活）；基准名 `_PROJECT`/`PROJECT_DIR` 谁唯一；字面量等值 vs 含子串。→ 口径钉死：Assign+AnnAssign 全形态（含 global 重绑）/基准名唯一化/右值 Str 恰 1 个且值恰为 `.daemon.lock`；红半边补注解赋值逃逸/函数内重绑/后缀改名。
**B3 exec 回收判据不可映射三联单**（D3#4）：「同三联单闭合」对象错位（搬函数 vs 停加载路径，拆除敏感方向相反）。→ 回收判据独立定义（连续 N 次全量绿走正常加载+exec 调用点=0+无 exec 下域门禁全过+删除加载器后差分同构），入 §八 3 拍板射程。
**B4 锁上下文第八槽「获取与等待语义」**（D4#1）：非阻塞获取 7 处/超时 1 处/条件等待 3 处——失败语义是业务语义（统一成常规持锁块=主循环挂死，HEAD 即 40s 挂死修复）。→ 增第八槽（阻塞/非阻塞失败语义/超时降级/条件等待-唤醒约定）；P0-5 清单加「获取模式」列。
**B5 P0-3 缺正确性校准**（D5#3）：「覆盖 100%+可复现」挡不住错误但稳定的分类器——写入目标分类/判据形态是 P0-5/P0-6 唯一权威。→ 补第三判据（已知正例对照+跨类混淆反例必须报出）。
**B6 模块级 `_host.X` 第六违规形态**（D6#3）：合规写法但 import 期时序非法（bind 未执行），检查器不拦。→ AST 判据：模块体非函数体作用域的 `_host` 属性访问即红。
