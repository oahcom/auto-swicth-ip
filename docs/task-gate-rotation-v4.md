### 0.2 git 隔离与提交规则（先于一切派工执行）

1. **基线三件套**：派工开始时记录 ① 基线 commit（必须出自干净索引——等并行会话提交，或明确 stash 隔离）；② 基线行数；③ 基线 pytest 快照（`pytest -q --tb=no -rA` 全量结果存档）。
2. **白名单 add**：只 `git add` 本阶段文件清单内的路径；工作树里并行会话的改动（config_projection/ledger_policy/daemon.py 段落等）一个不碰。
3. **整组提交**：daemon.py 与它 import 的未入库模块（如 config_projection.py）**同批提交**，防 HEAD import 断。
4. **验收口径**：以基线快照为准、**本阶段不新增红**（与基线快照比对 failed/error 集合）+ 列出已知红。不写「基线绿」——并行在途用例使基线不可能全绿。快照存 `.workbuddy/baseline/<日期>/`（pytest -rA 输出 + wc -l + commit 号）。
5. **monkeypatch 机械改豁免**：函数搬家后允许按机械规则改测试打桩目标（daemon.X → asip.X），断言与断言语义不得变；提交说明逐个列出被改测试行 + 等价性理由。取证：基线快照 vs 改后同命令比对。
6. **干净索引达成指令**：开工前 `git log -1 --format=%H` 记基线；工作树不净时用 `git worktree add ../asi-stage1 <基线 commit>` 在独立工作树开工（不动主树并行会话改动），交付 diff 回主树审。**豁免裁决**：凡提交含 daemon.py 的批次，必须同批 add `asip/config_projection.py`（daemon 已 import 它、未入库，单提 daemon.py 断 HEAD）——「一个不碰」指不改其内容，入库原样带上。

### 0.3 最小名词表（派工用；完整版见计划 §0）

**出站**=tag（选择器成员名）；**出口**=egress IP；**主体**=出口 IP（账本键）；**别名**=同主体下多个 tag；**grouping_level**=entry/egress/subject 的显式声明；**活跃出口**=窗口内有请求的不同出口；**请求数**≠选中次数；**回滞口**=策略模式切换判据；**原语闸**=写入原语上的总闸。

### 阶段 3a · 出口实测（B10）

**依赖**：1。**边界**：给每个节点建立「名字 → 实测出口」映射。测量**并入 dormant_probe 同一轮次**（复用其临时实例/全量 selector/端口分配/锁；curl 探活后追加一次 probe_egress；锁竞争=同轮内追加，不新增锁持有者）。**禁止复用 fetch_node_ip_region**；禁止另起独立测量器。成本入账：测量消耗请求额度，记入资源模型。
**产出**：映射表落盘（带测量时间戳）；未测出的标 `egress_unknown`（不进账不参与去重）。
**验收（P3-B‴，原语闸版，替代「抽查 20 个节点」）**：
- **闸**：在 selector 写入原语（`switch_proxy` / `_switch_warp` / `_slot_put` / `_proxy_gate_rotate_node` 的 PUT 点——**四个原语全装**，含 `_slot_put`：被 `_slot_claim`/`_refill_slots_from_probe` 调用、带 `_is_main_slot` 分支会动主出口）装 `_SELECTOR_WRITE_PAUSED` 总闸。暂停时记日志（含调用栈）并**拒绝写**（拒写≠中止测试）。不枚举调用方（10+ 处会漏），在原语层拦。
- **相位切换通道**：闸拒绝一切写，但 A-B-B-A 要求把主 selector 从 X 拨到 Z——**测试自身经测试特权通道直写**（带标记 bypass，计入拦截日志），其余写者一律被拦；每相位切换后重开括号读回。测试结束撤销 bypass。
- **回滚**：动两次主 selector（X→Z→X）后必须恢复**原选中项**（开工前记录），恢复后 keeper 接管确认（last_rotate_ts 推进）且主 selector 回读=原值。
- **0**：闸开；X、Z 使主出口 MX≠MZ（相等换 Z 重选）；Y 优先取非 X 非 Z。
- **0′（括号）**：每个 vi 采样前后各读 selector now（免费 GET），两次一致否则该 vi 作废重取——只信回读，不信 PUT 的 204（4 次「204 但 now 是别人」的失败模式）。
- **1**：v1≠v3 → Y 在 X 相位自身漂 → **不确定**（换 Y 重测，不计成败）。
- **2**：v2≠v2′ → Y 在 Z 相位自身漂 → **不确定**。
- **3**：v2≠v1 → 测量跟随主 selector 出口 → **失效**（阶段不通过）。
- **4**：v1==v3 且 v2==v2′ 且 v2==v1 → **通过**（共享出口也通过——不预设 1:1）。
- **中止**（记「不确定」不记通过）：遇 429 一次 / 回读不一致重试 3 次仍不一致 / 窗口 >5min / sing-box 不可用（GET /proxies 非 200）。
- **拦截≠中止**：keeper 每 tick 尝试写、被拒 N 次，是证据不是故障。记「闸已开，窗口内拦截 N 次写」。
- **静态门**（与主判据并列）：实现不出现 MIXED_PORT/7890/配置键/默认回落参数。
- **成本记录**：暂停起止、拦截次数、期间 429 数、消耗额度、恢复后 keeper 接管确认（last_rotate_ts 推进）。
- **判定顺序**：B‴ 先验测量 → P3-A 再看现象（iosapps 组：同 uuid、10 个不同 server、A 记录互异，实测出口去重数 ≥2。若 =1，先判「测量不可信或共享出口」，**不得反推同一台**）→ P3-C 覆盖（197 个有 server 成员全部有主体或显式 unknown）。
**禁止**：用生产 selector 测量不装闸；用静态键（配置指纹）冒充实测出口。

### 阶段 3c · 状态迁移（B9）

**依赖**：3b。**边界**：把 tag-keyed 状态迁到主体/出口。**性质是先清洗再迁移，不是改键名**。**基线口径（冻结快照）**：bad_nodes.json 持续被写（实测 21:00 156 → 21:30 158 → 22:00 162，约 +2 条/20min、不单调），**迁移基线以开工时刻导出的冻结快照为准**，漂移基准只进容量护栏、不进迁移输入；开工前清测试残留 `fake-dead-node-1`（test_auto_switch.py:304 泄漏进生产文件）。对象与口径（快照实数）：
- `.bad_nodes.json`（冻结快照实数为准，含 expire 已过存量——若只迁 active 会塌掉规模；无 fp → 反推标 `unverified`（不直接 verified_dead）。
- `.dormant_state.json`（247 条中 50 条判死全在配置，稳定可复现）：有 fp → 按**旧 fp** 迁移（old_fp 匹配/new_fp 不匹配→保留；old_fp 缺失/new_fp 匹配→不保留。单测锁此语义）。**双字段口径**：判死以 `alive=False` 为准；`result=dead` 而 `alive=True` 的 134 条按**矛盾记录**处理——保留但标 `state_conflict`，由下一轮探测重判，不直接进判死。
- `node_info.ip`（171 行）：**禁止继承为出口身份**（67 桶错 IP，测量机制注定错）；旧 ip 降级历史字段，出口只能来自 3a 实测。继承错 IP 条目数**必须 = 0**（可静态断言）。
- `.node_ip_used.json`：键不受漂移影响但内容含错 IP → 测量修复后清空/重建（起 `dirty_ip_avoidance=disabled` 标志 + 起止时间，429 率超阈值即回滚/缩短；可保留最近 1h）。
- `.egress_log.jsonl`：无 IP/fp，历史分布不可重建 → **S5 基线只能前瞻测量**（B10 覆盖率是 S5 出口级验收的前置，不是可选补全）；旧对照作废。

**流程（probe_first 默认）**：
1. 迁移进 pending（默认 probe_first：不参与选点、不计已判死、等下一轮探测定性）。`discarded` **精确定义**= tag 不在配置 **或** old_fp 缺失/无法核验——bad_nodes 的 155 条无 fp，但 tag 在配置 → **进 pending（unverified），不进 discarded**。
2. **pending 显式并入 dormant_probe 探测目标**（否则 155 条永远等不到探测）；TTL **双轨**：正常落态口径=**1 个实际探轮**（一轮内必须落三终态之一）；中断不计轮次但**硬超时 TTL=2 个实际探轮**（墙钟兜底，探测持续中断时触发）——到达硬超时落 verified_dead + `unverified_expired` 计数。
3. 探测定三终态：verified_dead / verified_alive（可回池）/ discarded。
4. **分批回池**：N = max(1, floor(活跃出口数 × 5%))/批，轮间隔 ≥ 探测周期；**活跃出口数取开工时刻 3a 映射表的实测值**（3c 在 3a 后，有数据；若 3a 未完成不得开工 3c）；未迁移条目旧状态仍权威、旧 tag 继续生效；整个迁移有截止时间；混用期做同指标观测记录。
5. **容量护栏**：可用候选 < 迁移前 80% → 暂停下一批 + 告警。
6. **混用期双轨裁决**：读取优先级=**新键优先、旧键兜底**（同 tag 新旧并存时新键说了算）；旧写者（update_node_info_async 等）在迁移期只写旧键、3c 结束统一停写；冲突演练用例：同一出口下新键 verified_alive、旧键判死 → 选点必须选它（新键胜）。

**验收（a–k，基数以开工时刻冻结快照实数为准）**：a) 计数守恒——**五桶穷尽互斥**：migrated / dropped_no_config / unverified / state_conflict / legacy_fp_matched（`legacy_fp_matched` 是 migrated 的**来源标注**，单独计数不入和；五桶之和=迁移前条目数）；b) 继承错 IP == 0；c) 单轮回池 ≤ N 且轮间隔有记录；d) unverified **正常 1 个实际探轮内**落三终态、硬超时 2 轮时落 `unverified_expired`（默认 probe_first 不选点）；e) 旧文件保留、新旧键并存观察窗、回滚触发条件明确且演练一次（回滚步骤：恢复旧文件→停新键读取→验证选点回到旧状态→报数）；f) pending 并入探测目标可断言（探测日志含这些 tag）；g) aborted 轮不计 TTL（模拟一次 abort）；h) 迁移有截止时间；i) 混用期指标与基线对照有记录；j) 容量护栏演练（模拟跌破 80% → 暂停+告警）；k) 双轨冲突演练（新键 alive 旧键判死 → 新键胜）。
**禁止**：一次性翻状态；继承 node_info.ip；重算指纹全表失配。

### 阶段 4 · 计量（S3）

**依赖**：{2, 3b, 3c}。**边界**：把阶段 2 的服务事实按连接摊分归因到主体（出口），得**估算的请求级用量**，误差标注（keep-alive 下连接≠请求）。持久化，**废 1200 秒清零**（内存字典降级纯缓存或删除）。`node_info.call_count` 列：**先停写 + 观察窗，再删列**（与并行会话的台账生命周期改动解耦，等其入库稳定后进行；删列不可回滚故排最后）。
**不做**：分配策略。
**产出**：每个出口有估算请求数，随时间递增、重启不丢。**验收**：连续 1 小时计数单调不减；重启后可读；与 connections 总量守恒（误差 ≤ 标注值）；确定性单测（给定连接序列，摊分结果正确）。
**禁止**：把「选中次数」当请求数写账；per-name 计数。

### 阶段 5 · 分配（S4）——杠杆是回滞口与打分，不是默认值

**依赖**：4。**边界**：① 打分依据从「延迟/选中次数」换**出口剩余额度**（保留 P2C 抽样，只换打分）；② **回滞口改造**——「pressure→normal：错误率达标**或样本总数<3**」改为有最小驻留 + 足够样本量的判据（现网 33 段 pressure 中位 41s、累计 17.4h，驻留由采样窗口决定）；③ 清零策略与 4 一致。有状态调度器（1b 留下的）在本阶段随语义重构进公共模块（状态归属按 1c 三列表）。
**不做**：改去重；改 429；不以「改默认模式标签」为手段（实测 pressure 已是主态之一，90.2% 轮换照旧由 429 触发——空杠杆）。
**产出**：打分随剩余额度变化；驻留不由采样窗口决定。**验收**：确定性单测——给定剩余额度向量变化，打分严格单调、选点分布随额度摊平（合成 5000 次选点；统计容差：任一出口份额偏离期望 ≤ 3σ 或写明所用检验）；回滞判据单测（样本 <3 不触发回切；最小驻留生效）；「任一出口占比」类指标**只作 5+6 联合观测**（候选不放开做不到），不进本阶段验收。
**禁止**：为了分散强制轮转；把压力测试期的 9 秒/单份日志当基线。

### 阶段 6 · 去重（S5）——别名模型

**依赖**：3b（**不依赖 4**——「组内按用量轮换」已删：同主体用量恒等，数学上不可能）。**边界**：① 分组键=3b 实测出口（`grouping_level=egress`；覆盖率 <95% 时降级 `entry` 级并**显式声明**，`egress_unknown` 计数响亮输出——沿用 T5「绝不洗成通过」）；② 组内**不排序竞争**，同主体多 tag 是**别名**：选别名=探测新鲜度 TTL（取 dormant-probe.timer 实际轮次 ×1–2，**不硬编码**）；全组 stale/dead 走**持久化轮次游标**（重启不归零，禁止静默回第一条）；**不按延迟选**；③ 未测节点按 entry 保守分组、不进 egress 分母；两个 unknown（egress/credential）分开计数。
**不做**：改分配；改窗口大小。
**产出**：候选数回到实测出口数；分组层级显式。**验收（五条）**：
1. 每个有活别名的组恰好 1 个候选，**候选数 == 有活别名组数**（无活组单列「不可用组」不算失败）——堵「干脆不去重」；
2. 凭证差分：不同 uuid→不同**身份**（主体仍=出口，身份区分不进账本键）、同 uuid→同身份、缺 uuid→显式报错禁哈希空串；
3. 缺实测不把不同 server 判同出口（离线用例）；
4. 输出七个外部可读字段（/debug/state 或验收报告）：`grouping_level / group_count / candidate_count / denominator / egress_unknown / credential_unknown / coverage`；等式只在「声明层级 + 已测子集」上成立——防覆盖率越低越容易过的假通过；egress 级仅当 coverage≥95% 开启（未达=前置未完成，非阶段失败）；
5. 降级响亮：entry fallback 输出 `egress_unknown=<n>` 计数+日志。
「≥80%」单列**容量指标**（数据属性非实现错误，分母=实测出口数或池规模须写明）。
**说明**：剔除 dead 后全组 stale 时走游标；全 dead 落「不可用组」（验收 1 已单列），不走游标。
**禁止**：新写身份键；用 block_view 键；静默降级。

### 阶段 7 · 429 语义（S6）

**依赖**：{3b, 4}。**边界**：① **归属判别信号先行**——出口级（Retry-After 量级 + 该出口近期用量指向额度耗尽）vs 账号级（同一凭据摘要跨出口仍 429）；② 出口级：硬冷却到 Retry-After 时刻（无 RA 时用保守默认）+ **换节点**（机场模型下有效）；③ 账号级：该凭据下节点冷却/停用 + 告警，**不判死、不换节点**；④ 状态写 `ledger_policy` 的 ban_until（**扩展它**）。
**不做**：改判死。
**归属判别信号（可操作版，1:1 模型注意）**：默认档=出口级（误判代价不对称：把账号级误判成出口级只是多换节点，把出口级误判成账号级会停用整账号反向误杀——拿不准一律按出口级处理）。账号级需**三选二**才成立：① 同凭据摘要下 ≥2 个出口各自用量**远低于额度下限**（如 <30%）却同时 429（反证不是各自烧完）；② Retry-After 量级显著高于出口级历史基线（基线由 §2.2 blocked_ips 数据建）；③ 换到全新出口（实测不同）立即 429。「同出口换账号」在 1:1 模型下结构性不可得，**不作信号**。误判率进验收记录。
**产出**：Retry-After 内同一出口不被选中；归属分层处理。**验收**：≥10 次 429 样本（自然发生或注入式录播），断言 0 次在 Retry-After 前重打同一出口；归属判别单测（构造出口级/账号级场景各命中、构造「多出口独立烧完」场景必须不误判为账号级）；账号级 429 产生告警而非判死。
**禁止**：在 429 处加退避状态机（阶段 0 刚清，理由是行为变更未经对齐）；新建第二套惩罚状态。

### 阶段 8 · 判死（S7）+ 工程健壮性（S8）

**依赖**：5（判死与用量交叉验证需要额度状态）。**边界**：① 判死前置「连续 N 次 + 与用量交叉验证」（额度耗尽≠链路坏）；判死键用 3c 迁移后的主体/出口；② 池成员漂移：**自建 known 集**（禁 compare_members），纳入自愈与告警，正向用例=人为删一个池成员必须报 drift；③ 同一写入函数的两个入口（rotate 持 `_API_LOCK`、keeper 不持锁）**互斥/单飞**（同刻最多一个在途）——是加互斥，不是收敛写者（PUT 点本就只有一个）。池成员漂移部分**合并进并行会话的既有漂移实现**（对方提交后），本阶段只补池成员维度。
**产出**：复测为通的不再判死；漂移必告警；同刻单写在途。**验收**：假阳性率单测（构造复测通场景不判死）；drift 正向用例必红→修复→必绿；并发写注入测试（双线程同刻 rotate，回读一致）。
**禁止**：扩大自愈自动动作范围（只报告与限速自愈）。
